# SWEX Rune JSON 스펙 정리 (Summoners War Exporter)

이 문서는 SWEX(Summoners War Exporter)로 추출된 JSON의 **룬(Rune)** 구조를 정리한 것입니다.  
`rune_list`(또는 `runes`) 배열의 원소가 “룬 하나”이며, 장착 룬(`unit.runes`)과 별개로 **룬 자체의 스탯/상태 정보**가 들어 있습니다.

## 기본 정보 (Basic Info)

- **`rune_id`**: 룬 고유 ID
- **`wizard_id`**: 계정(마법사) 고유 ID
- **`occupied_type`**: 장착 위치
  - `1`: 몬스터에 장착
  - `2`: 인벤토리(미장착)
- **`occupied_id`**: 장착 중인 몬스터의 unit_id
  - `0`이면 미장착
- **`slot_no`**: 룬 슬롯 번호 (1~6)
- **`class`**: 룬 성급(별)
- **`rank`**: 태생 등급
  - `1`: 일반, `2`: 마법, `3`: 희귀, `4`: 영웅, `5`: 전설
- **`upgrade_curr`**: 현재 강화 수치 (+0 ~ +15)
- **`extra`**: 현재 등급(강화 후 등급) — 태생 등급과 동일한 숫자 체계

## 옵션 종류 ID

`set_id`, `pri_eff`, `sec_eff`, `prefix_eff`에서 “옵션 종류”를 식별할 때 사용합니다.

### 능력치 종류 (Effect ID)

- `1`: 체력(+)  
- `2`: 체력(%)  
- `3`: 공격력(+)  
- `4`: 공격력(%)  
- `5`: 방어력(+)  
- `6`: 방어력(%)  
- `8`: 치명 피해(%)  
- `9`: 치명 확률(%)  
- `10`: 효과 적중(%)  
- `11`: 공격속도(+)  
- `12`: 효과 저항(%)  

### 룬 세트 (Set ID)

- `1`: 활력 / `2`: 수호 / `3`: 신속 / `4`: 칼날 / `5`: 격노 / `6`: 집중 / `7`: 인내 / `8`: 맹공  
- `10`: 절망 / `11`: 흡혈 / `13`: 폭주 / `14`: 신보 / `15`: 응보 / `16`: 의지 / `17`: 보호 / `18`: 반격 / `19`: 파괴  
- `20`: 투지 / `21`: 결의 / `22`: 고양 / `23`: 명중 / `24`: 근성 / `25`: 봉인 / `26`: 무형  

## 부옵션 배열 구조 (sec_eff)

부옵션은 **4개의 값을 가진 배열**의 리스트입니다.

형식: `[[능력치ID, 수치, 연마여부, 변환여부], ...]`

- **능력치ID**: 위 Effect ID 참조
- **수치**: 해당 옵션의 총합 (기본값 + 연마값)
- **연마여부**: 연마석으로 올라간 수치 (0이면 연마 안 함)
- **변환여부**: 보석(변환) 사용 여부
  - `0`: 기본
  - `1`: 변환됨
  - 참고: 데이터 버전에 따라 5 이상 특정 숫자로 표기되기도 함

## 기타 수치

- **`pri_eff`**: `[옵션ID, 수치]` (주옵션)
- **`prefix_eff`**: `[옵션ID, 수치]` (접두어 옵션)
- **`base_value`**: 룬 가치(판매가 산정용 내부 수치)
- **`sell_value`**: 매각 시 획득 마나석

## 프로젝트(DB) 저장 매핑

본 프로젝트는 `swex_rune` 테이블에 다음처럼 저장합니다.

- **식별/장착정보**
  - `rune_id`, `wizard_id`
  - `occupied_type`
  - `occupied_id` → `unit_id`(동일 의미로 사용)
  - `slot_no` → `slot`
- **등급/강화**
  - `class` → `grade`
  - `rank` → `rank`
  - `upgrade_curr` → `level`
  - `extra` → `extra`
- **옵션**
  - `pri_eff` → `main_stat_type`, `main_stat_value` + `pri_eff_json`
  - `prefix_eff` → `innate_stat_type`, `innate_stat_value` + `prefix_eff_json`
  - `sec_eff` → `substats_json`
  - 원본 룬 JSON 전체 → `raw_json`
